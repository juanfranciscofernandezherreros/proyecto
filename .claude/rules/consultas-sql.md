# Consultas a la base de datos

Toda consulta SQL ejecutada contra la base de datos del proyecto se guarda en
`sql\consultas\` como `AAAA-MM-DD_HHMM_<tema>.sql`, con el SQL exacto y la cabecera
de `sql\consultas\_PLANTILLA.sql` (leerla antes de escribir el fichero). Las de
escritura se marcan `ESCRITURA` y se guardan **antes** de ejecutarlas.
