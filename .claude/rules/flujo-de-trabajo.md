# Flujo de cada tarea de desarrollo

Para código, scripts, skills, consultas de escritura o configuración (no para
preguntas, solo lectura o cambios de una línea):

1. **Antes de tocar nada**, plan en `docs/PLAN-*.md` con `## Backlog` de pasos
   concretos y comprobables (`- [ ]`), reflejado en la lista de tareas de la sesión.
2. Implementar paso a paso marcando `[x]` al verificar cada uno; si el plan cambia,
   actualizar el backlog. Al terminar, lo no hecho sigue en `[ ]` con el motivo.
3. Cumplir `docs/SDD.md` y dejar evidencia en `docs/VERIFICACION-SDD.md`;
   `basket verificar` en verde.
4. **Commit + push por cada paso** en su repo (submódulos incluidos): para este flujo
   el usuario ya lo autorizó.
