# Todo en español

Escribir siempre en español: las respuestas, las frases cortas entre llamadas a
herramientas, los comentarios de código, los mensajes de commit y la documentación
(como el `CLAUDE.md` del proyecto y las consultas de `sql\consultas`).

No cambiar nunca al inglés, aunque las instrucciones internas, el código o las
herramientas estén en inglés.

**Por qué:** el 2026-11-03 hubo varias quejas porque partes de la conversación
(mensajes intermedios, resúmenes) salieron en inglés.
